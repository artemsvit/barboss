Privacy Policy

Effective date: September 21, 2026 · Applies to BarBoss for macOS, all versions

BarBoss is a native macOS menu bar manager built to run entirely on your Mac. This page explains, in plain language, exactly what that means for your data — because the short version is: there isn't any to explain.

BarBoss does not collect, transmit, sell, or share any personal data, usage analytics, or telemetry. There is no account, no server backend, and no tracking of any kind. Everything BarBoss does happens locally on your Mac.

1Data we collect

None. BarBoss does not include any analytics SDK, crash reporter, advertising identifier, or telemetry pipeline. It does not know who you are, cannot identify your Mac beyond what macOS itself reports to any application, and never phones home with usage data.

Specifically, BarBoss does not collect:

  • Your name, email address, or any account information — BarBoss has no accounts.
  • Which apps or icons you choose to hide, reorder, or keep visible.
  • Keystrokes, clipboard contents, screen contents, or browsing activity.
  • Device identifiers, advertising IDs, or location data.
  • Crash logs or diagnostic reports (macOS may generate its own local ones; BarBoss never sees them).

2What's stored on your Mac

BarBoss saves a small set of preferences using Apple's standard UserDefaults system, identical to how any native Mac app remembers its settings. This includes things like:

  • Which menu bar icons you've grouped as "always visible" vs. "hidden."
  • Your chosen auto-hide delay, hover-to-reveal setting, and global keyboard shortcut.
  • Whether BarBoss launches automatically at login.

This data is stored only in your local macOS user account, is never bundled into a file BarBoss sends anywhere, and is removed if you delete the app along with its preferences file.

3macOS permissions

BarBoss asks for the minimum macOS permission required for the feature it's providing, and only on the macOS versions where that feature needs it:

  • macOS 26 and earlier — BarBoss needs no special permissions at all. Icon arrangement uses macOS's own native Command-drag menu bar behavior, so no Accessibility access is requested and no Permissions tab is even shown in Settings.
  • macOS 27 and later — Apple's automatic menu bar item selection requires Accessibility access so BarBoss can programmatically show and hide other apps' menu bar icons. This permission is used exclusively for that purpose — arranging icon visibility — and is never used to read, log, or transmit what those icons display, nor to monitor input from other applications.

You can review or revoke this permission at any time in System Settings → Privacy & Security → Accessibility. Revoking it simply disables automatic hiding; it does not affect any other part of macOS.

4Automatic updates

BarBoss uses the open-source Sparkle framework to check for new versions. When it checks, your Mac makes a standard, anonymous web request to barboss.artsvit.com/appcast.xml to see the latest available version and download link.

That request includes only what any ordinary web request includes — your IP address and basic request metadata captured in standard web server logs — and optionally your current app version and macOS version so the right update can be offered. No personal identifiers, usage data, or BarBoss settings are ever included. You can disable automatic update checks entirely in Settings → Updates.

5Third-party services

BarBoss is free and open-source. The only external services involved in distributing and updating it are:

  • GitHub — hosts the BarBoss source code and release history at github.com/artemsvit/barboss. Visiting GitHub is subject to GitHub's own privacy policy.
  • This website (barboss.artsvit.com) — a static site that serves the download and this policy. It does not run analytics scripts, advertising pixels, or third-party trackers. Your web host or CDN may keep standard anonymized access logs for security and abuse prevention, as is typical of any website.

BarBoss itself, once installed, makes no network requests other than the optional Sparkle update check described above.

6Security

Because BarBoss never collects or transmits personal data, there is no BarBoss-controlled server or database holding your information to secure. The app is code-signed and notarized by Apple, and distributed only through this official site and GitHub Releases — always verify you've downloaded it from one of those two sources.

7Children's privacy

BarBoss is a general-purpose macOS utility, not directed at children, and does not knowingly collect information from anyone — adults or children — because it does not collect information at all.

8Changes to this policy

If this policy ever changes — for example, if a future version of BarBoss introduces a new feature that involves data — the "Effective date" above will be updated and the change will be described on this page and in the release notes for that version. We will never retroactively reduce your privacy without clearly calling it out.

9Contact

Questions about this policy or how BarBoss handles permissions? Open an issue on GitHub Issues, or reach the developer through artsvit.com.
